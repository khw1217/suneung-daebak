# 🎯 수능 대박

수능을 대박 치고 싶은 모든 수험생을 위한 **목표 달성 공부 루틴 생성기** (2028학년도 수능 체제 기준)

과목별 현재 점수·등급과 목표를 입력하면, 목표까지 남은 점수가 큰 과목에 공부 시간을 더 배정한 하루 공부 시간표를 만들어 줍니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `streamlit_app.py` | 프로그램 본체(파이썬 코드) |
| `index.html` | 웹사이트 첫 화면. 같은 폴더의 `streamlit_app.py`를 브라우저 안에서 실행 (stlite 사용) |
| `requirements.txt` | 내 컴퓨터에서 실행할 때 필요한 패키지 목록 |

## 내 컴퓨터에서 실행

```
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## 웹사이트로 게시 (GitHub Pages)

1. GitHub에서 Public 저장소를 만들고 세 파일을 업로드
2. Settings → Pages → Source: Deploy from a branch → Branch: `main`, `/(root)` → Save
3. 잠시 후 `https://아이디.github.io/저장소이름/` 에서 접속

`streamlit_app.py`를 수정해 커밋하면 사이트에도 그대로 반영됩니다.

## 기능

1. 과목 정보 관리 (2028 수능 6과목: 국어·수학·영어·한국사·통합사회·통합과학)
2. 성적 입력 받기
3. 절대평가 등급 계산 (영어 90점↑ 1등급·10점 간격, 한국사 40점↑ 1등급·5점 간격)
4. 목표 점수 검사
5. 공부 가능 시간 계산
6. 공부 시간 배분 (비중 = 0.15 + 남은 점수 ÷ 만점, 10분 단위)
7. 공부 방법 추천 (남은 비율 20%↑ 개념 복습, 5%↑ 기출·오답, 그 외 실전 풀이)
8. 시간표 생성
9. 결과 표시·CSV 저장
